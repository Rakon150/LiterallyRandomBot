# LiterallyRandomBot
Minimal Slack bot for literally random stuff — dice, numbers, coins and more

The bot didnt take a long time to make but it was a good practice working with JS and making a bot.

## Features
 - /lrb-dice - rolls a dice with the number of selected faces
 - /lrb-range - picks a random number from a range
 - /lrb-coin - flips a coin
 - /lrb-shuffle - shuffle a list of things
 - /lrb-8ball - answers yes/no questions
 - /lrb-password - generates a random password
 - /lrb-choose - chooses a random entry

Other commands:
 - /lrb-help - shows the help page
 - /lrb-ping - checks bot latency
